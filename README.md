# DONT CHEAT!
*A game in which you will be breaking its rules...*

![Gameplay](images/gameplay.png)

## Play
- [Play in browser (itch.io)](https://tiko12321.itch.io/break-the-rules)

## Jam Info
Made in 96 hours for **Macro Game Jam** (Theme: *Break the rules*). Solo dev.

## Controls
| Action | Key |
|--------|-----|
| Move   | WASD |
| Jump   | Space |
| Close Windows   | Enter |
| Activate "Cheats" | Number Keys |

## About
Progress through levels while avoiding being caught by the security system. Use "cheats" to help yourself move on further.
